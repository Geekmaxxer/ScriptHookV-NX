# Shared port support

`port.hpp` contains the Switch platform/UI/ownership adaptation by MEGATARD,
using the ScriptHookV-NX headers and license from the repository root.

`locations.hpp` adapts the MIT-licensed location tables from root-cause's
v-spjammerhunt, v-pizzaboy, v-sptreasurehunt and v-spkiller. `mine_data.hpp`
adapts v-spmines/default_data.xml. `components.hpp` adapts the SPGunLocker
component catalog. The matching upstream revisions, source hashes and MIT
notices are kept in the corresponding port folders. Retain those notices
when redistributing these data headers or their compiled derivatives.
