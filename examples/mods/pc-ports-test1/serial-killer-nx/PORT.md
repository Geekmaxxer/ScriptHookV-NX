# Los Santos Slasher NX - Test 2

Original: [root-cause/v-spkiller](https://github.com/root-cause/v-spkiller/tree/604fcc435a88d06816954939d5ffb18015b94eda), MIT license.
Switch adaptation: MEGATARD (@Geekmaxver), using ScriptHookV-NX.

Four original clues, a randomized original van site, two-minute night/countryside ambush, hostile killer, $50,000 completion, Navy Revolver and original home reward pickup sites.

The badge explains stage and unmet ambush requirements. Waypoints update with
the investigation; nearby clue/van interaction also has an explicit menu action.

## Differences from the PC mod

PC phone messages, camera effects, custom killer wardrobe and audio hints are not implemented. Missing clue/weapon DLC needs installation; no fallback object or free quest-completion action is used. The gameplay menu provides guidance but does not bypass investigation stages.

This is a native gameplay adaptation with a replaced platform/UI layer, not a
feature-identical PC binary conversion. Local build and mocked-runtime checks
do not establish Switch gameplay, visual quality or performance.

See the [test guide](../README.md) for controls and installation. Source hashes
and the pinned revision are in upstream.json. Retain LICENSE.upstream.txt when
redistributing upstream-derived code or data.
