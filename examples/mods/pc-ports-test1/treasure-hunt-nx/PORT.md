# Treasure Hunt NX - Test 2

Original: [root-cause/v-sptreasurehunt](https://github.com/root-cause/v-sptreasurehunt/tree/abcfcf93d1841eac8a4dff814032035f0a0bd33c), MIT license.
Switch adaptation: MEGATARD (@Geekmaxver), using ScriptHookV-NX.

Randomized original note/chest sites, three original clues, persistent stage progression, Double-action Revolver unlock and five original home reward pickup sites.

Objectives set waypoints automatically. Investigate using D-Pad Right nearby,
or the menu's nearby-objective action; both require the actual clue and distance.

## Differences from the PC mod

Map/menu guidance replaces photo emails, custom investigation cameras, synchronized search scenes, audio hints and the decorative final-chest tableau. No clue is bypassed by its menu. Required Doomsday props/weapon data must already be installed.

This is a native gameplay adaptation with a replaced platform/UI layer, not a
feature-identical PC binary conversion. Local build and mocked-runtime checks
do not establish Switch gameplay, visual quality or performance.

See the [test guide](../README.md) for controls and installation. Source hashes
and the pinned revision are in upstream.json. Retain LICENSE.upstream.txt when
redistributing upstream-derived code or data.
