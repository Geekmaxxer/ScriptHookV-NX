# Signal Jammer Hunt NX - Test 2

Original: [root-cause/v-spjammerhunt](https://github.com/root-cause/v-spjammerhunt/tree/28a0148a74ac205c3a0817f5eea2ba4ca833cd5c), MIT license.
Switch adaptation: MEGATARD (@Geekmaxver), using ScriptHookV-NX.

All 50 original sites and rotations; closest-jammer streaming; $2,000 rewards and $50,000 completion; saved bitset; optional map guidance; three original Thruster reward generators.

## Differences from the PC mod

PC notification/audio-bank presentation and decorative effects are replaced by HUD notices. The required Casino Heist prop and Thruster model must already exist in the installation. Only the closest jammer within 250 metres is streamed.

This is a native gameplay adaptation with a replaced platform/UI layer, not a
feature-identical PC binary conversion. Local build and mocked-runtime checks
do not establish Switch gameplay, visual quality or performance.

See the [test guide](../README.md) for controls and installation. Source hashes
and the pinned revision are in upstream.json. Retain LICENSE.upstream.txt when
redistributing upstream-derived code or data.
